# CUDA Vector Processing Benchmark

## Описание проекта

В данной работе выполнено исследование производительности обработки больших векторов с использованием GPU-ускорения через CUDA Python.

Реализованы и сравнены три подхода:

- последовательные вычисления на Python;
- векторизированные операции NumPy;
- параллельные вычисления на GPU с использованием CUDA.

---

# Используемые технологии

- Python
- NumPy
- Numba CUDA
- Pandas
- Matplotlib

---

# Реализованный алгоритм

Программа выполняет обработку векторов различного размера.

Для каждого размера:

1. создаются входные данные;
2. выполняется вычисление на CPU;
3. выполняется вычисление на GPU;
4. измеряется время выполнения;
5. вычисляется ускорение CUDA;
6. проверяется корректность результатов.

---

# CUDA-реализация

GPU-версия реализована с использованием:

```python
@cuda.jit
```

Каждый CUDA-поток обрабатывает отдельный элемент массива.

Параллельное выполнение позволяет существенно сократить время обработки больших объёмов данных.

# Анализ результатов

## Малые размеры массивов

Для небольших векторов GPU показывает меньшую эффективность из-за:

- затрат на запуск CUDA kernel;
- передачи данных между CPU и GPU;
- недостаточной загрузки потоковых мультипроцессоров.

Поэтому для `N = 1024` ускорение отсутствует.

---

## Большие размеры массивов

При увеличении размера данных CUDA начинает эффективно использовать параллелизм GPU.

На максимальном размере массива:

```text
N = 4194304
```

получено ускорение:

```text
1416.56x
```
